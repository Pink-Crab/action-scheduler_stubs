# Action Scheduler Stubs

Action Scheduler stubs for static analysis (PHPStan, Psalm, IDEs), generated by
[stub-forge](https://github.com/Pink-Crab/stub-forge) with
[php-stubs/generator](https://github.com/php-stubs/generator).
Includes private and protected members. Each git tag matches the plugin
version the stubs were generated from.

## Source

- Original plugin: <https://github.com/woocommerce/action-scheduler>
- Plugin homepage: <https://actionscheduler.org>

## Installation

```
composer require --dev pinkcrab/action-scheduler_stubs:4.0.0
```
